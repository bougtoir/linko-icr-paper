# Information Contribution Ratio (ICR / LINKO)

Code and data for the manuscript *"The Information Contribution Ratio: a
reproducible descriptor of endpoint informational weight in meta-analysis, and
what it does and does not diagnose"* (prepared for *Statistics in Medicine*).

Everything reported in the manuscript - every number, table and figure - is
generated by the pipeline below and read back by the manuscript builder. No
result is typed into the text; `scripts/audit_manuscript.py` fails the build if
a number in the manuscript cannot be traced to a generated result file.

## Reproduce from a clean clone

```bash
git clone <repository>
cd icr_paper
make setup        # python3 -m venv .venv && pip install -r requirements.txt
make all          # download data, run analysis, audit, build manuscript
```

`make all` runs:

1. `scripts/download_ist.sh` - downloads the International Stroke Trial
   individual participant data from the University of Edinburgh DataShare
   repository (<https://datashare.ed.ac.uk/handle/10283/124>) into `data/ist/`.
2. `run_analysis.py` - simulation study, negative control, redundancy analysis,
   published-trial analyses, IST principal component analysis and leave-one-out
   sensitivity, early-convergence analysis, and all figures. Results are written
   to `results/` as CSV plus a single `results/results.json`, with software
   versions and the git commit recorded in the metadata.
3. `scripts/audit_manuscript.py` - checks numeric traceability, citation order,
   figure/table citation, abstract length and claim wording.
4. `generate_docx.py`, `generate_pptx.py`, `scripts/generate_cover_letter.py` -
   build the submission files.

Runtime is about 5 minutes with the default 1000 simulation iterations. Use
`make analysis ITER=50 CONV_ITER=20 SENS_ITER=20` for a smoke run.

## Inputs

| Path | Contents | Source |
|---|---|---|
| `data/statin_studies.csv`, `data/statin_table1.csv` | effect estimates and baseline tables, 5 statin trials | primary publications, see `data/study_sources.csv` |
| `data/glucose_control_studies.csv`, `data/glucose_control_table1.csv` | effect estimates and baseline tables, 4 intensive glucose-control trials | primary publications, see `data/study_sources.csv` |
| `data/study_sources.csv` | citation, DOI and extraction note for every study | - |
| `data/ist_country_codes.csv` | IST country code to country name mapping | IST documentation |
| `data/ist/IST_corrected.csv` | IST individual participant data (not committed; downloaded) | Edinburgh DataShare, handle 10283/124 |

Simulation parameters (number of variables, sample sizes, treatment effect,
spillover fraction, iteration counts) are literals in `run_analysis.py` and
`src/simulation.py` because they define the data-generating mechanism; they are
reported in the manuscript Methods.

## Outputs

| Path | Contents |
|---|---|
| `results/results.json`, `results/*.csv` | every quantity reported in the manuscript |
| `LINKO_manuscript_english.docx` | submission manuscript: tables after the references, figure legends only |
| `LINKO_manuscript_english_with_figures.docx` | reading copy with figures inline |
| `LINKO_manuscript_japanese.docx` | Japanese reference translation (text only) |
| `LINKO_tables_english.docx` | editable tables |
| `LINKO_figures_english.pptx` | editable figure deck, one figure per slide |
| `figures/submission/Figure_N.tif`, `.png` | separate figure files at 600 dpi with `figure_index.csv` |
| `cover_letter_statistics_in_medicine.md` | cover letter, numbers read from `results/` |

## Layout

```
src/simulation.py           data-generating mechanism and scenarios
src/icr_calculator.py       ICR_std and ICR_raw estimators
src/meta_analysis.py        fixed-effect and DerSimonian-Laird pooling
src/sensitivity.py          REML, Paule-Mandel, Hartung-Knapp, prediction
                            intervals, Monte Carlo SEs, negative control,
                            redundancy analysis
src/ist_pca_analysis.py     PCA-based estimators on IST data
src/ist_sensitivity.py      leave-one-out recomputation
src/real_world_analysis.py  published-trial analyses
src/data_io.py              CSV inputs and provenance
src/results_loader.py       result access and number formatting
src/manuscript_content.py   manuscript text; all values come from results
src/figure_export.py        separate journal-resolution figure files
```
